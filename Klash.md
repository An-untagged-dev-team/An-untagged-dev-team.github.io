# Klash Shaders
Klash Shaders is a brand new resource pack who replace Better Vibrant Visuals

These shaders contains these awesome features:
- Lighty day, darky night
- Enhanced PBR design ( without and heightmap or normal )
- Beatiful Water
- And more
